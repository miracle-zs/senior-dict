# 银发字典 (Senior Dict) - 专为长辈设计的识字查字助手

面向中老年人设计的极简查字工具，解决长辈在日常阅读（报纸、药品说明书、手机文章、家谱）中“遇到生僻字/不认识的字不知道怎么查”的痛点。
**100% 纯离线运行，零流量消耗，无任何广告弹窗。**

## 完整产品核心功能清单

1. **拍照点查（指哪查哪）**：
   - 拍照后原位定格画面，端侧 PP-OCRv6 毫秒级自动高亮识别出的汉字（暖黄色柔光框）；
   - 长辈只需用手指轻触任一字块（内置 48px 防手抖扩大热区），底部瞬间滑出超大字卡片；
   - 包含模糊/未识别时的贴心适老提示（“没看清，靠近点再拍一次”）。
2. **离线真实手写识别（大字田字格）**：
   - 真实笔迹光栅化引擎，用户在全屏田字格书写后，调用端侧 OCR 识别生成候选汉字标签大按钮；
   - 点选候选字直接大声朗读并查看大白话解释，笔顺随意也能准确识别。
3. **生字本与查字历史（温故知新）**：
   - 查字卡片一键【⭐ 存入生字本】；
   - 顶部快捷进入“温习生字”面板：分组查看“我的生字本”与“查字历史”；
   - 列表卡片右侧内置独立大声朗读大喇叭，无需繁琐进入详情即可随时复听。
4. **微信截图 / 相册图片导入识字**：
   - 拍照按钮旁配备【相册图片】入口，支持从系统相册选取微信好友发来的说明书、药盒照片或截图；
   - 自动启用 `OcrImageResizePolicy` 1280px 动态采样，彻底杜绝 50MP/100MP 手机拍照 OOM 崩溃。
5. **取景器补光灯（手电筒）**：
   - 取景界面右上角悬浮【补光灯】开关，暗光环境下（如床头看药盒、夜间看配料表）一键照亮拍摄区域。
6. **偏旁拆字反查（解决“会拆不会拼”）**：
   - 支持自然语言口述输入：“左边木右边白”、“草字头加约”；
   - 提供 10 个常用快捷偏旁标签（木、艹、氵、亻、扌、口、讠、钅、火、日），点击一键填入并毫秒级显示候选生字。
7. **长辈个性化设置面板**：
   - **朗读语速调节**：极慢（0.6x，适合高龄长辈）、适中（0.8x，默认清晰推荐）、标准（1.0x）；
   - **语音生活助记词开关**：朗读时是否带生活组词（如“柏，柏树的柏”）；
   - **触控震动反馈开关**：轻触字块时震动触感确认。
8. **专属高辨识度 App 品牌图标**：
   - 适配 Android 自适应矢量图标（深邃宝蓝底色 + 暖金放大镜轮廓 + 醒目大字），桌面上极易辨认。
9. **正式发布混淆加固 (R8 / Proguard)**：
   - 针对 Room 实体、JNI C++ 桥接接口、ONNX Runtime 进行完整的防混淆保护，发布版本兼具稳定性与紧凑体积。
